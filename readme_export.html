1. Project Overview

In semiconductor VLSI engineering, physical design parameters—such as silicon area ($\mu\text{m}^2$), critical path delay ($\text{ns}$), and dynamic/leakage power dissipation ($\mu\text{W}$)—traditionally require time-intensive iterative synthesis and place-and-route (P&R) cycles. The AI-Based VLSI Analyzer addresses this by providing instant physical metric prediction across process nodes (from 45nm down to 7nm) using a trained multi-output regression model, combined with an automated optical die scanner that localizes and inventories functional hardware components.

⚡ Predict Chip Details (Metrics Engine)

Synthesizes physical scaling laws to estimate total cell area, propagation delays, dynamic switching power, and static leakage with real-time SVG charting.

🔬 Silicon Layout Scanner (Vision Engine)

Executes Normalized Cross-Correlation (NCC) template matching on chip layouts to identify ALUs, SRAM memory caches, registers, and clock generators with 5-step auditable OCR checks.

3. Machine Learning & Computer Vision Algorithms

A. Multi-Output Random Forest Regressor

The regression engine takes 5 physical hardware parameters: cell_count, seq_ratio (sequential flip-flop ratio), tech_node (nm), voltage (V), and frequency (MHz). An ensemble of 100 decision trees calculates targets simultaneously:

Physical Scaling Formulations:
• Area Scaling ($\mu\text{m}^2$): $\text{Area} = N_{\text{cells}} \times A_{\text{base}} \times \left(\frac{\text{tech\_node}}{45}\right)^2 \times \eta_{\text{routing}}$
• Propagation Delay ($\text{ns}$): $\text{Delay} = (N_{\text{cells}} \cdot 0.0003 + 1.1) \times \left(\frac{\text{tech\_node}}{45}\right) \times \left(\frac{1.1}{V}\right)$
• Total Power ($\mu\text{W}$): $P_{\text{total}} = \underbrace{\alpha C_{\text{gate}} V^2 f \cdot N_{\text{cells}}}_{P_{\text{dynamic}}} + \underbrace{N_{\text{cells}} \cdot I_0 \cdot e^{0.08(45 - \text{tech\_node})} \cdot \frac{V}{1.1}}_{P_{\text{leakage}}}$

B. Normalized Cross Correlation (NCC) Component Detection

Layout component discovery evaluates template similarities against normalized die scans:

$$R(x,y) = \frac{\sum_{x',y'} (T'(x',y') \cdot I'(x+x',y+y'))}{\sqrt{\sum_{x',y'} T'(x',y')^2 \cdot \sum_{x',y'} I'(x+x',y+y')^2}}$$
• Bounding boxes exceeding threshold $R \ge 0.75$ are consolidated via OpenCV's groupRectangles ($\text{groupThreshold}=1, \epsilon=0.2$).

5. REST API Specifications

1. Metrics Prediction Endpoint

POST /api/predict (Content-Type: application/json)

// Request Body
{
  "cell_count": 5000,
  "seq_ratio": 0.25,
  "tech_node": 14,
  "voltage": 1.0,
  "frequency": 1200
}

// Response (200 OK)
{
  "area": 1245.82,
  "delay": 1.38,
  "power": 210.45
}

2. Component Detection Endpoint

POST /api/detect (Content-Type: multipart/form-data)

// Request: Form data field 'image' containing layout image file (.png, .jpg)
// Response (200 OK)
{
